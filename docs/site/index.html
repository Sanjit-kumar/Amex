The idea in one paragraph

Merchants send us transaction records in whatever format they have. Today a team of about 50 people converts each one by hand into the Amex standard CSV and checks every transaction before sales uses it. This project replaces the manual conversion with AI agents and keeps one human step: a reviewer compares the original file with the standardized result, fixes anything wrong, and approves it. Only approved data reaches the sales team.

Glossary

Term Meaning
Standard format The fixed set of 13 transaction fields every record is converted to (schema)
Level 1 / 2 / 3 The three AI stages: vision, text, convert (pipeline)
Fast path Structured files with recognizable headers are mapped by code, with no AI call
Record One standardized transaction. A file contains one or many
Version Every edit creates a new version. Version 1 is always the AI's original output
Curated store The output of approved records only. This is what sales consumes
Mock mode Demo mode used when no AI credentials are configured. It must be off in real use
